# Submission Checklist

The assignment's explicit submission requirements are the complete system prompt and a public link to call recordings and call logs (audio + transcript). The supporting approach documents below are recommended extras.

## Required deliverables

- [ ] **Complete system prompt text** — final version used by the configured agent.
- [ ] **Public call-evidence link** — points to recordings and call logs.
- [ ] **Audio recordings** — multiple scenarios, not just one happy-path call.
- [ ] **Transcripts** — corresponding to the recorded test calls.

## Recommended supporting material

- [ ] Brief explanation of the architecture and state-management approach.
- [ ] Test matrix with actual pass/fail results.
- [ ] Evidence links mapped to test scenario IDs.
- [ ] Notes on known limitations and unresolved assumptions.
- [ ] Confirmation that shared artifacts are accessible to the evaluator.

## Final quality check

- [ ] Required business rules are reflected in the prompt.
- [ ] The configured agent was actually tested on the chosen platform.
- [ ] The final prompt version matches the version tested.
- [ ] Failures in critical scenarios were corrected and regression-tested.
- [ ] No unsupported exact rate or minimum property value is claimed.
- [ ] Public recordings and logs do not expose unnecessary personal or sensitive information.
- [ ] The README/docs hub links work and documents agree with one another.

## Status

All checkboxes are intentionally unchecked until the artifacts are created and verified. Do not claim that recordings, transcripts, deployment, or tests exist until they do.
